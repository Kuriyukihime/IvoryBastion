# Character audio tools

The current shipped voices are three spoken female AI announcements, generated by `generate_bastion_voice.py` and finished by `finish_bastion_voice.py`. Siege R uses “Onslaught protocol engaged. Enjoy the fireworks.” with the same voice description and seed as Mobile/Aegis. The toolset also retains experimental nonverbal synthesis and audio-event screening for future work. Earlier laughter candidates and the licensed recording are development archives. Sources, floating-point output and generation settings are retained before any PCM finishing. These development models are never embedded in the mod.

## Model downloads

Run `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/download_audio_models.ps1`. It uses the installed Hugging Face CLI, eight concurrent file workers, and eight concurrent range requests for Xet transfers. Eight download batches is the user's default for future Hugging Face model downloads. `-Model laughter` or `-Model screening` limits the download; `-HttpOnly` is available when Xet is unavailable. `-HfCli` accepts another installed CLI path.

The laughter model is `ResembleAI/chatterbox-turbo` (MIT); screening uses `MIT/ast-finetuned-audioset-10-10-0.4593` (BSD-3-Clause). Reference video/audio supplied by the user stays under `.build/reference` for analysis and is not a generation input or shipped asset.

## Reuse for other characters

`generate_turbo_laugh.py --model MODEL_PATH --reference CHARACTER_VOICE.wav --output-dir OUTPUT_FOLDER --seed 501 --text "[laugh] [laugh] [laugh]"` accepts a character's voice recording longer than five seconds. Run it in the Chatterbox Python environment. Without a reference argument it constructs a voice reference from Ivory Bastion's own generated mobile/Aegis lines. It does not use the rejected siege chuckles as a voice reference.

`classify_laugh_takes.py TAKE1.wav TAKE2.wav --report REPORT.json` screens candidates using the local AudioSet model. Run it in the Transformers environment. Inspect several leading classes; scores are not calibrated quality ratings. A strong laughter score can help reject speech, whimpering or screaming, but does not establish maniacal acting, naturalness or listener approval.

Finish a selected take with minimal processing, retaining its original vocal rhythm and pitch wherever possible. Keep source checksums, selection times, joins, any gain envelope and effects in the editing recipe. Store an explicitly versioned WAV preview beside the ZIP so previews cannot silently point to an older version.

Validate PCM format, duration, true peak, source/preview equality, build resources and package contents. Report listening limitations plainly; automated checks are not listening.
